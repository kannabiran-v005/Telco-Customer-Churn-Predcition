Telecom Customer Churn Prediction Using MLP
This project aims to predict customer churn in the telecom sector using a Multi-Layer Perceptron (MLP) neural network. The dataset contains customer demographics, account information, and service usage details. The model is trained to classify whether a customer is likely to churn (leave the company) or not. The project includes data preprocessing, one-hot encoding of categorical features, feature scaling, training of an MLP model with three hidden layers of 45 neurons each, and evaluation using accuracy, confusion matrix, and classification report. Additionally, the trained model can take new customer data as input and predict churn probability, making it interactive for business use cases.
